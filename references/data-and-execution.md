# 数据与执行映射

## 输入及取数

脚本仅需Python标准库，取数使用Node与已安装的`ifind-finance-data/call-node.js`。不要把iFinD密钥、账户号码、真实持仓截图或完整历史数据装入技能。

先核实代码与产品，再选择stock/fund服务；基金代码不能替代T+0/T+1产品核验。常见标准主板/创业板A股买入100股整数倍；ETF通常100份，但特殊产品仍以官方规则为准。当前未覆盖科创板最低200股及其他特殊交易单位。

行情每月分批，避免iFinD返回截断。曾出现“最低价”被解析成区间最低价，必须检查原始表头和指标语义；缺少每日最低价就重新查询，不能填充区间最低价。只保留目标证券标识，不把`.OF`净值或别名混入`.SH/.SZ`场内价。

- 同日重复OHLC不一致、乱序、未来日期、非正价格、最高/最低逻辑错误必须失败。
- 来源返回节假日占位但OHLC为空，记录后过滤；工作日缺失须核实停牌/休市，不能假装全年无缺口。可与同市场已验证的流动标的交易日历交叉核对。
- 保留原始响应、请求范围、抓取时间、symbol、复权口径、缺失/过滤/重试记录及数据SHA256。
- 报告截止日在盘中时，不把尚未结束的日K线当成完整观察值。快照与历史数据分开保存。
- iFinD当前高频工具仅支持当日日内查询；没有真实历史分钟数据就明确日线情景模拟。

## 公司行动文件

运行前创建JSON，例如：

```json
{
  "verified": true,
  "checked_through": "2026-10-13",
  "source_urls": ["实际核验的官方公告URL"],
  "events": [],
  "other_actions": []
}
```

发生现金分红时：`events`填`{"date":"YYYYMMDD","cash_per_share":税前每股现金额}`，date为除息日，不是公告日。核实权益登记/除息关系。只有完成证据核验后才能写`verified:true`；日期覆盖数据末日。脚本不把布尔值当外部真实性证明，调用agent负责证据来源。

A股现金分红用保守20%税后应收进入总权益，到账日未知时不作为期间可用资金，期末假设结算；这不是精确按持有期追缴的税务模型。ETF分红按产品适用税收说明核对。转增/送股/拆分不在当前模型内，不能直接喂未复权价格；有事件先报告不支持，不能偷偷换前复权价凑结果。

## 交易模型与费用

A股支持T+1：当日卖出受隔夜可卖库存限制，不是“全天不能做任何买卖”。有旧仓可以先买后卖旧仓，但不能无限循环卖掉当天新仓。止损先卖旧仓，新仓等下一可成交交易日，末日禁止新增买入；一字价/停牌日不假定能成交，期末未清仓须标出未实现部分。

ETF应核实结算方式，不按“所有ETF均T+0”处理。报价单位ETF0.001元、股票0.01元。默认佣金来自本用户已确认的研究假设；新费率覆盖它。股票卖出印花税万五、双边过户费十万一是编写时基线，应核实研究区间及当前适用规则；不要把净佣/全佣混淆后重复计规费。

公开核验入口（重新读取适用规则，不把链接存在当实时确认）：
- 深交所交易规则：https://www.szse.cn/lawrules/index.html
- 上交所ETF问答：https://www.sse.com.cn/assortment/fund/etf/question/
- 2023证券印花税减半公告：https://shanghai.chinatax.gov.cn/zcfw/zcfgk/yhs/202308/t468451.html

## 统计与解释

周期从末日向前对齐，60个交易日观察值包含建仓日和清仓日，约59个收盘收益间隔；不要称自然季度。每轮从相同预算独立开始、末日清仓计成本，不将四轮拼接成真实复利净值。

统计对象是每轮总盈亏。报告均值、样本方差（n-1）、标准差、最差一轮、最大高点回撤；停止线按初始预算5%，所以高点回撤可能超过5%。先比较均值/方差Pareto候选，辅助排序使用两条人工路径中的低均值和高标准差；这个比值没有证明统计显著性或未来优势。四轮不是大量独立样本，不通过重叠滚动窗口假装增加样本量。

列出持有不动、相同本金止损和现金对照，避免把降低仓位误当网格超额收益。对最高分候选做适用的滑点敏感性检查，不能看到验证结果后改规则再声称未见盲测。

## 从结果到APP

只在用户要配置时按其真实界面映射。重要对应：

| 模型 | 页面对应与限制 |
|---|---|
| 初始价 | 新策略启动参考价；附时间，不把成本价自动填作基准 |
| 基准更新 | 模型按成交价更新；“到价触发就更新”是另一机制 |
| 间距 | 输入框已有%时填0.5代表0.5%，不是0.005 |
| 手数 | 股/份数量，不是资金金额；禁止无说明加倍 |
| 仓位范围 | 指总持仓，不是可用数量，也不是“大约可买” |
| 买入/卖出报价 | 限价：买用卖一、卖用买一；仍可能不成交 |
| 有效期 | 区分自然日/交易日；软件最长20/60自然日不等于研究周期 |
| 自动运行 | “自动下单”不证明云端托管；退出APP/断网的行为查当前官方说明 |
| 策略停止 | 最大持仓、价格区间均不等于本金止损；停止网格也不等于平仓 |

同花顺专业终端文档不能套到手机APP。原生券商APP是否支持仓位上下限/云端/联动退出，要逐项读说明或截图；截图未显示的字段不能声称已设置。

用户要求无人值守时，不建议靠逐笔手动确认维持原模型。平台不能实现必要控制时，输出具体缺口并查兼容的原生执行入口；不擅自删除风控或宣称可直接运行。严格交替买卖是不同策略，需另算，不能沿用原收益。

新建/迁移同一标的网格前核对旧单状态，避免两个客户端重复运行。A股从空仓建底仓后需可卖库存才能完整启动双向网格；ETF根据已核实结算规则执行。技能本身不提交任何金融订单。
